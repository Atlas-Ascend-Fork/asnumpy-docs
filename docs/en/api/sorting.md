# Sorting Functions

This module provides sorting and ordering functions.

::: info
Sorting functions are currently under development. Please refer to the NumPy documentation for the expected API.
:::

## Planned Functions

- `asnumpy.sort` - Return a sorted copy of an array
- `asnumpy.argsort` - Returns the indices that would sort an array
- `asnumpy.lexsort` - Perform an indirect stable sort
- `asnumpy.partition` - Return a partitioned copy of an array
