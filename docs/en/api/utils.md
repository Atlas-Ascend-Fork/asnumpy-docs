# Utilities

This module provides utility functions for asnumpy.

::: info
Utility functions are currently under development. Please refer to the NumPy documentation for the expected API.
:::

## Planned Functions

- `asnumpy.copy` - Return a copy of the array
- `asnumpy.shape` - Return the shape of an array
- `asnumpy.size` - Return the number of elements
- `asnumpy.ndim` - Return the number of dimensions
- `asnumpy.dtype` - Return the data type
