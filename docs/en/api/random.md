# Random Sampling

This module provides random number generation functions for various probability distributions.

::: info
Random sampling functions are currently under development. Please refer to the NumPy documentation for the expected API.
:::

## Planned Functions

- **Distributions**: Various probability distribution functions
  - `asnumpy.random.rand` - Uniform distribution
  - `asnumpy.random.randn` - Standard normal distribution
  - `asnumpy.random.randint` - Random integers
  - `asnumpy.random.random` - Random floats
