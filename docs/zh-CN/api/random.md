# 随机抽样

本模块提供各种概率分布的随机数生成函数。

::: info
随机抽样函数目前正在开发中。请参阅 NumPy 文档了解预期的 API。
:::

## 计划中的函数

- **概率分布**: 各种概率分布函数
  - `asnumpy.random.rand` - 均匀分布
  - `asnumpy.random.randn` - 标准正态分布
  - `asnumpy.random.randint` - 随机整数
  - `asnumpy.random.random` - 随机浮点数

## 参见

- [`numpy.random`](https://numpy.org/doc/stable/reference/random/index.html): NumPy 随机模块
