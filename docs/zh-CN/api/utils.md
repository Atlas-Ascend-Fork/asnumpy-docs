# 工具函数

本模块提供 asnumpy 的工具函数。

::: info
工具函数目前正在开发中。请参阅 NumPy 文档了解预期的 API。
:::

## 计划中的函数

- `asnumpy.copy` - 返回数组的副本
- `asnumpy.shape` - 返回数组的形状
- `asnumpy.size` - 返回元素数量
- `asnumpy.ndim` - 返回维度数
- `asnumpy.dtype` - 返回数据类型

- [`numpy`](https://numpy.org/doc/stable/reference/index.html): NumPy 参考
